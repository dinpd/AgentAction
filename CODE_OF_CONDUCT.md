# Code of Conduct

AgentPass is an open source project for governing AI agent tool execution. The
project works best when discussion is direct, evidence-based, and respectful.

## Expected Behavior

- Be respectful of different experience levels, backgrounds, and viewpoints.
- Discuss ideas, code, policies, and risk models on their technical merits.
- Assume good intent, but accept correction when impact does not match intent.
- Keep disagreement focused on facts, tradeoffs, and project goals.
- Credit prior work and link sources when relevant.
- Avoid sharing private information, secrets, customer data, or non-public
  security details in public project spaces.

## Unacceptable Behavior

- Harassment, threats, intimidation, stalking, or sustained disruption.
- Personal attacks, insults, or derogatory comments.
- Sexualized language or imagery in project spaces.
- Discriminatory comments related to identity, background, or protected class.
- Publishing someone else's private information without explicit permission.
- Publicly disclosing a vulnerability before maintainers have had a reasonable
  opportunity to investigate and coordinate a fix.
- Spam, trolling, or repeated off-topic promotion.

## Scope

This code applies in all AgentPass project spaces, including issues, pull
requests, discussions, community channels, release notes, and project events. It
also applies when someone represents AgentPass in another public venue.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or limit
participation when behavior violates this code. Serious or repeated violations
may result in a ban from project spaces.

Reports can be sent to the project maintainers through a private channel. If a
report involves a security issue, follow [SECURITY.md](SECURITY.md).

Maintainers will handle reports as privately as practical, gather context before
acting when possible, and avoid conflicts of interest in enforcement decisions.
