# Support

AgentPass support happens in public project spaces unless the topic involves a
security vulnerability or private data.

## Where to Ask

- Use GitHub issues for bugs, feature requests, documentation gaps, and design
  questions.
- Use pull requests for concrete changes.
- Use private vulnerability reporting for security issues. See
  [SECURITY.md](SECURITY.md).

## What to Include

For bugs, include:

- Package or component affected
- Version, commit, or branch
- Runtime versions, such as Python or Node.js
- Minimal reproduction steps
- Expected behavior and actual behavior
- Relevant policy, schema, receipt, or tool-call input with secrets removed

For design questions, include:

- The agent runtime, gateway, or provider shape you are integrating with
- The tool actions you need to guard
- The approval, replay, audit, or PII boundaries that matter
- Any compatibility constraints

## Commercial Support

This repository does not currently publish a commercial support offering. Public
issues and pull requests are handled according to maintainer availability.
